# UX DesignOps Interactive Learning Website
This project is an interactive learning website for first-year UX students who want to know more about DesignOps.
It was built as a frontend-only educational experience that introduces users to the role of a UX Design Operations
team in an engaging and interactive way. Instead of presenting information as a static page, the website guides users
through a series of lesson modules that combine short explanations with activities so they can apply what they learn
right away.

### Purpose
The goal of this project is to help beginner UX students understand what DesignOps is as well as how it supports UX
teams. Many students learn about the different aspects of UX design early on, but may not yet understand the systems
and structures that allow design teams to work effectively. This website helps bridge that gap.

### Features
Interactive module-based learning experience
Visually engaging landing section
Progress tracking throughout the lesson
Multiple activity types, including:
- quizzes
- checklist selection
- matching activities
- reflection prompts
- scenario-based questions
- Final scenario challenge where users apply DesignOps thinking to a realistic team problem
- Smooth navigation from the hero section to the main lesson content
- Fully frontend-based with no backend or data collection

### Tech Stack
This project uses:
- React
- Vite
- Tailwind CSS
